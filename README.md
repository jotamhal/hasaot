# לוח ההסעות — מוקאפ

מוקאפ אינטראקטיבי לאפליקציית תיאום הסעות של הורים לחוגי ילדים.

**הדגמה בלבד** — אין שרת, אין חשבונות, ושום דבר לא נשמר. רענון הדף מאפס הכל.
כל הנתונים בדויים.

👉 https://jotamhal.github.io/hasaot/

## מה יש בפנים

- **מסך החוגים** — סטטוס שבועי לכל חוג, ופס "הקרוב" שאומר מי אוסף ומי מחזיר
- **מסך החוג** — ריבוע ליום, מחולק לשניים: *מגיעים* (הילד שלי) ו*מסיעים* (הרכב שלי, הלוך/חזור)
- **שיבוץ אוטומטי** — מי נוסע עם מי, נפתח בתוך הריבוע
- **זרימת הצטרפות** — יצירת חוג, והצטרפות מקישור הזמנה
- **הגדרות** — ילדים, חוגים, משפחות ומנהלים, הרכב שלי
